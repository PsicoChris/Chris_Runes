ᚠ Oráculo de Runas (Futhark Antiguo)

Una aplicación web interactiva inspirada en la tradición nórdica que permite realizar tiradas y lecturas simbólicas de las **24 runas del Futhark Antiguo**, con soporte para orientaciones (derecha e invertida), animaciones de volteo y descripciones detalladas mediante burbujas informativas (*tooltips*).

Características Principales

* Saco Ancestral Interactivo: Arrastra las runas desde la bolsa virtual o haz clic para extraerlas una a una de forma aleatoria (simulando una tirada real).
* Orientaciones (Derecha e Invertida): Cada runa tiene una probabilidad del 50% de salir invertida, alterando dinámicamente su significado y su representación visual (rotando el glifo).
* Tarjetas con Animación 3D: Haz clic en cualquier runa extraída para voltearla de manera fluida y descubrir su símbolo.
* Información Detallada (Tooltips): Al mantener el cursor sobre una runa, aparecerá una burbuja flotante con su significado profundo adaptado a su posición (normal o invertida).
* Gestión de Bolsa: Control visual de las runas restantes (de 24 a 0) y un botón para reiniciar la bolsa y comenzar una nueva lectura.
* Diseño Responsivo (*Mobile-Friendly*): Interfaz optimizada tanto para ordenadores como para dispositivos móviles.


Tecnologías Utilizadas

* HTML5 (Estructura semántica y atributos de accesibilidad ARIA).
* CSS3 (Variables CSS, diseño moderno con Flexbox, transformaciones 3D y gradientes personalizados).
* JavaScript (ES6+) (Lógica de arrastre, barajado aleatorio, manipulación del DOM y gestión de estados).
